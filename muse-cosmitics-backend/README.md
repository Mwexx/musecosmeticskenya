# Muse Cosmetics Backend API (MongoDB)

Complete e-commerce backend for Muse Cosmetics using MongoDB.

## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0
- MongoDB >= 6.0 (local or MongoDB Atlas)
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd muse-cosmetics-backend
